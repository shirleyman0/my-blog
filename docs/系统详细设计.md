
**数据查询**：
```typescript
const { data: post, error } = await supabase
  .from("blog_posts")
  .select("*")
  .eq("slug", slug)
  .not("published_at", "is", null)
  .single();
```

**静态生成**：
```typescript
export async function generateStaticParams() {
  const { data: posts } = await supabase
    .from("blog_posts")
    .select("slug")
    .not("published_at", "is", null);

  return posts?.map((post) => ({ slug: post.slug })) || [];
}
```

|--------|------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 项目 URL | 是 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 匿名密钥 | 是 |

**客户端初始化**：
```typescript
const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL;
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY;

// 环境变量验证
if (!supabaseUrl || !supabaseAnonKey) {
  console.warn("Missing Supabase environment variables");
}

export const supabase = createClient(
  supabaseUrl || "",
  supabaseAnonKey || ""
);
```

## 4. 数据库详细设计

### 4.1 表结构

**表名**：`blog_posts`

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PRIMARY KEY | `gen_random_uuid()` | 主键 |
| title | TEXT | NOT NULL | - | 文章标题 |
| slug | TEXT | UNIQUE, NOT NULL | - | URL 标识 |
| content | TEXT | NOT NULL | - | Markdown 内容 |
| excerpt | TEXT | - | - | 文章摘要 |
| author | TEXT | NOT NULL | `'Admin'` | 作者 |
| published_at | TIMESTAMPTZ | - | NULL | 发布时间 |
| created_at | TIMESTAMPTZ | - | `NOW()` | 创建时间 |
| updated_at | TIMESTAMPTZ | - | `NOW()` | 更新时间 |
| tags | TEXT[] | - | `'{}'` | 标签数组 |

### 4.2 索引设计

| 索引名 | 字段 | 类型 | 用途 |
|--------|------|------|------|
| `idx_blog_posts_slug` | slug | B-tree | 加速 slug 查询 |
| `idx_blog_posts_published` | published_at DESC | B-tree | 加速列表排序 |

**创建语句**：
```sql
CREATE INDEX idx_blog_posts_slug ON blog_posts(slug);
CREATE INDEX idx_blog_posts_published ON blog_posts(published_at DESC);
```

### 4.3 RLS 策略

**启用 RLS**：
```sql
ALTER TABLE blog_posts ENABLE ROW LEVEL SECURITY;
```

**策略定义**：

| 策略名 | 操作 | 条件 | 说明 |
|--------|------|------|------|
| `public_read` | SELECT | `published_at IS NOT NULL` | 公开读取已发布文章 |
| `auth_insert` | INSERT | `auth.role() = 'authenticated'` | 认证用户可创建 |
| `auth_update` | UPDATE | `auth.role() = 'authenticated'` | 认证用户可更新 |

**创建语句**：
```sql
-- 公开读取
CREATE POLICY "public_read" ON blog_posts
  FOR SELECT USING (published_at IS NOT NULL);

-- 认证写入
CREATE POLICY "auth_insert" ON blog_posts
  FOR INSERT WITH CHECK (auth.role() = 'authenticated');

CREATE POLICY "auth_update" ON blog_posts
  FOR UPDATE USING (auth.role() = 'authenticated');
```

## 6. 错误处理

### 6.1 环境变量验证

**位置**：`src/lib/supabase.ts`

```typescript
if (!supabaseUrl || !supabaseAnonKey) {
  console.warn(
    "Missing Supabase environment variables. " +
    "Please set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY"
  );
}
```

### 6.2 数据库错误处理

**列表页**：
```typescript
if (error) {
  console.error("Error fetching posts:", error);
  // 显示空列表或错误提示
}
```

**详情页**：
```typescript
if (error || !post) {
  notFound(); // 触发 404 页面
}
```

### 6.3 404 处理

使用 Next.js 内置的 `notFound()` 函数：
```typescript
import { notFound } from "next/navigation";

// 文章不存在时
if (!post) {
  notFound();
}
```
